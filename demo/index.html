hpd-lookup

New York City publishes every HPD housing violation as open data. This turns it into something a tenant can read.

GitHub npm MIT licensed Zero dependencies

One component, any brand

The same element, twice. Nothing differs between them except CSS custom properties set on the host — no forked stylesheet, no build flag, and nothing reaching inside the shadow root.
